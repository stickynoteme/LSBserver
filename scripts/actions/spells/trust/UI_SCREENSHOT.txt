KEY FEATURES:
═════════════

1. THREE BUTTONS IN TOP RIGHT (left to right):
   
   ╔════════════════════╗
   ║ Restore to Default ║ ← Loads sys/defaults/curilla.json
   ╚════════════════════╝   Restores trust to original state
   
   ╔═══════════╗
   ║ Clear All ║ ← Resets form to blank/empty state
   ╚═══════════╝   Removes all gambits, mods, gear
   
   ╔═════════════╗
   ║ Save Trust  ║ ← Saves to userdata/curilla.json
   ╚═════════════╝   Generates Lua file


2. AUTOMATIC DEFAULT LOADING:
   
   When you select a trust from the dropdown:
   
   Step 1: Check userdata/curilla.json
           ↓ exists          ↓ doesn't exist
           Load user data    Step 2 →
   
   Step 2: Check sys/defaults/curilla.json
           ↓ exists          ↓ doesn't exist
           Load defaults     Blank form


3. TYPICAL USER WORKFLOWS:

   Workflow A: First-Time User
   ────────────────────────────
   1. Select "curilla.lua" → Defaults load automatically
   2. See 3 gambits, auto-attack enabled
   3. Modify as needed
   4. Click "Save Trust"
   
   Workflow B: Experienced User Customizing
   ─────────────────────────────────────────
   1. Select "ayame.lua" → Loads previous customizations
   2. Make changes
   3. Click "Save Trust"
   
   Workflow C: User Made Mistake
   ──────────────────────────────
   1. Edited "shantotto.lua" incorrectly
   2. Click "Restore to Default"
   3. Confirm → Back to original defaults
   
   Workflow D: Start From Scratch
   ───────────────────────────────
   1. Select "moogle.lua"
   2. Click "Clear All"
   3. Confirm → All fields empty
   4. Build custom trust
   5. Click "Save Trust"
